# 小学英语（yingyu）

和近代史 / 作业页分开。自己的文件夹：`tools/fuxi/yingyu/`。入口只有这一个网页，不要从 fuxi 首页中转。

本地：打开 `index.html`  
线上：`/yingyu/`（**等你说推再推**）

顶上自选（顺序：笔记 → 词库 → 主题 → 多邻国）：

- **笔记版**：自己收集的单词 / 语句
- **词库**：按词性浏览（名/动/形/副/代/数/介/连/感叹/限定冠词 + 多义词 + 组合词）；点标签不拽回左边；本地 = `lexicon.js` + `lexicon-extra.js`
- **主题**：默认 / 雾灰护眼 / 像素风 + 字号
- **多邻国版**：年级路径，点「开始」开一局

查中译：先本地词库 → 在线翻译兜底。本地没有且网络/接口失败时会显示「未填」，可点字段手改。

## 多邻国版
1. 选年级，沿路径点当前关「开始」
2. **认词**：闪卡，中→英 / 英→中，点卡片翻面
3. **开一局**：这一单元混合抽最多 10 题。句子题不够时用本章单词补默写
4. 答完点底部「继续 / 知道了」再下一题
5. 结束页看星星，可再来一局

## 笔记版
- **单词**：点「保存」→ 查词后弹出标签选择（已有 / 自定义）再收藏。
- **标签**：横滑「全部 + 自定义标签」，默认收起；点标签展开查看。标签名可自建。
- **语句**：问句 + 回答 + 解释，同样按标签存放。
- **喇叭**：只播真人词典 mp3。键：`fuxi-yingyu-notes-v1`、`fuxi-yingyu-note-tags-v1`。
- **同步（抄作业页）**：导出文本 / 导出 JSON / **上传** → 仓库 `yingyu/notes-latest.json`；另一端导入合并或「从云端覆盖」。本机空笔记时自动拉云端。
- **文案要短**：中译 / 课本只到「中·三年级上」（不要 Unit 名）；不展示「来源」；少啰嗦标签。

## 结构
- `data.js` — 词库未改：三年级上 6 个 Unit 五种题型齐全；其它年级多为词表
- `index.html` — 同一个入口：多邻国版路径 + 笔记版单词本
- 进度：`localStorage` → `fuxi-yingyu-progress-v1`（对/错、当前年级单元）。首页「进度导出 / 导入」
