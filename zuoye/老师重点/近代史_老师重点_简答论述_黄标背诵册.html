第1章　进入近代后中华民族的磨难与抗争（8 道）

【简答】6 道

1. 抗日战争胜利后中国国内的三种建国方案。
  1. 北洋军阀/国民党：大地主大资产阶级专政，续走半殖民地半封建道路
  2. 中间派：资产阶级共和国，走独立发展资本主义道路
  3. 中国共产党：工农联盟人民共和国，经新民主主义到社会主义
2. 中国的封建社会的特点。
  1. 经济：封建地主土地所有制占主导
  2. 政治：高度中央集权的封建君主专制
  3. 文化：儒家思想为正统
  4. 社会结构：封建宗法等级（君权、父权、夫权）
3. 近代中国工人阶级的产生。
  1. 先于中国资产阶级产生
  2. 来源：破产农民、手工业者；早期多在外资在华企业
  3. 特点：革命性最强、与农民天然联系、集中便于组织
4. 近代中国社会的主要矛盾和近代以来中华民族面临的历史任务。
  1. 主要矛盾：帝国主义与中华民族；封建主义与人民大众
  2. 历史任务：民族独立、人民解放；国家富强、人民富裕
5. 19世纪末帝国主义列强瓜分中国的图谋未能实现的主要原因。
  1. 帝国主义列强矛盾无法协调（门户开放等）
  2. 中华民族不屈不挠的反侵略斗争
6. 旧民主主义革命时期中国人民反侵略战争失败的原因。
  1. 根本：社会制度腐败（封建统治腐朽）
  2. 重要：经济技术落后

【论述】2 道

1. 近代中国社会的半殖民地半封建的基本特征。
  1. 帝国主义操纵中国财政经济与政治，成支配力量
  2. 封建势力与侵略势力勾结，成统治支柱
  3. 自然经济破坏，但地主土地所有制仍广存
  4. 民族资本主义弱小，受双重压迫且有联系
  5. 经济政治文化发展极不平衡，割据分裂
  6. 人民尤其农民贫困破产、毫无政治权利
2. 简述资本—帝国主义对中国的军事、政治、经济、文化控制。
  1. 军事：侵略战争、屠杀、割地、划分势力范围
  2. 政治：控制内政外交、镇压反抗、扶植代理人
  3. 经济：勒索赔款、控制海关与金融、倾销商品资本输出
  4. 文化：宗教渗透、办报办学、奴化思想

第2章　不同社会力量对国家出路的早期探索（10 道）

【简答】9 道

1. 《天朝田亩制度》和《资政新篇》的性质。
  1. 《天朝田亩制度》：最能体现太平天国社会理想，反封建纲领（空想）
  2. 《资政新篇》：近代中国首个发展资本主义方案（未实施）
2. 洋务运动的历史作用。
  1. 客观上促进早期工业与民族资本主义
  2. 开启近代教育，传播新知
  3. 引起社会风气与价值观念变化
3. 简述洋务派创办的新式学堂。
  1. 翻译学堂（如京师同文馆）
  2. 工艺学堂
  3. 军事学堂（如船政学堂）
4. 洋务运动失败的原因。
  1. 封建性：维护封建统治，对列强有依赖
  2. 中央无健全领导，地方各自为政
  3. 中体西用，不能根本使中国富强
5. 资产阶级维新派宣传维新变法的主要活动。
  1. 著书立说、介绍西学
  2. 办学会、办报纸
  3. 兴学堂
  4. 上书光绪帝（公车上书等）
6. 19世纪末，维新派与守旧派论战的主要问题及意义。
  1. 焦点：要不要变法；要不要兴民权、设议院、行君主立宪；要不要废八股、改科举、兴西学
  2. 意义：传播维新思想，形成思想解放潮流，推动变法展开
7. 戊戌维新运动的意义。
  1. 爱国救亡运动：救亡图存、发展资本主义
  2. 资产阶级政治改良：主张君主立宪，突破中体西用
  3. 思想启蒙：传西学、批纲常，打开封建思想缺口
  4. 移风易俗：戒鸦片缠足、剪辫易服等
8. 简述戊戌维新运动失败的主要原因。
  1. 不敢否定封建主义，依靠皇帝、幻想列强、脱离群众
  2. 守旧势力强大，光绪帝无实权，新政昙花一现
9. 维新派本身局限性的表现。
  1. 不敢否定封建主义（托古改制等）
  2. 对帝国主义抱有幻想
  3. 惧怕人民群众，未发动群众

【论述】1 道

1. 太平天国农民起义的历史意义。
  1. 沉重打击封建统治与外国侵略势力
  2. 是中国旧式农民战争最高峰
  3. 冲击孔子和儒家经典的正统权威
  4. 有的领导人主张与各国通商交往
  5. 推动亚洲民族解放，冲击西方殖民

第3章　辛亥革命与君主专制制度的终结（9 道）

【简答】7 道

1. 简述清末“新政”实行的原因。
  1. 内忧外患：革命兴起，清政府为延续统治被迫“新政”
2. 辛亥革命时期资产阶级革命派的骨干力量。
  1. 资产阶级、小资产阶级知识分子（留学生与国内新式学堂学生）为骨干
3. 20世纪初资产阶级革命派与改良派论战的主要内容及意义。
  1. 内容：要不要以革命推翻清廷；要不要共和；要不要改变封建土地所有制
  2. 划清革命与改良界限，传播革命思想，为辛亥革命作准备
4. 中华民国临时政府的成立性质、局限性。
  1. 性质：资产阶级共和国性质的革命政权
  2. 局限：承认不平等条约、幻想列强、未彻底反帝反封建
5. 北洋军阀的专制统治。
  1. 军阀割据、政局动荡
  2. 独裁专制、破坏民主
  3. 投靠帝国主义
6. 辛亥革命失败后资产阶级革命派为挽救共和而进行的武装斗争。
  1. 二次革命、护国运动、护法运动等武装斗争
7. 辛亥革命失败的主观原因。
  1. 没有提出彻底反帝反封建纲领
  2. 不能充分发动和依靠人民群众
  3. 不能建立坚强革命政党

【论述】2 道

1. 试述孙中山先生三民主义学说的内容及其意义。
  1. 民族主义：推翻清廷，建立民族独立国家（未鲜明反帝）
  2. 民权主义：推翻君主专制，建立资产阶级共和国
  3. 民生主义：平均地权（未彻底解决农民土地）
  4. 意义：比较完备的资产阶级民主革命纲领，推动革命发展
2. 辛亥革命的历史意义。
  1. 推翻封建帝制，创建亚洲第一个资产阶级共和国
  2. 沉重打击帝国主义在华势力
  3. 推动民族资本主义与社会风气解放
  4. 打击帝国主义侵略，推动亚洲民族解放
  5. 促使中国人民思想解放，打开进步闸门

  3. 为抗战和中国革命胜利提供思想理论武器
6. 中国人民抗日战争在世界反法西斯战争中的地位。
  1. 中国战场是世界反法西斯战争东方主战场
  2. 为盟国提供大量战略支持与牵制
  3. 与反法西斯力量相互支援，共同胜利
7. 抗日战争胜利的原因。
  1. 以爱国主义为核心的民族精神是决定因素
  2. 中国共产党中流砥柱作用

  4. 世界反法西斯力量同情与支持

【简答】4 道

1. 新中国成立初期面临的考验。
  1. 巩固新生人民政权
  2. 恢复国民经济
  3. 完成民主革命遗留任务
  4. 争取有利国际环境
2. 抗美援朝胜利的意义。
  1. 打出新中国国威军威，提高国际地位
  2. 为经济建设与社会改革赢得相对稳定的和平环境
3. 中国共产党提出的过渡时期总路线反映了历史的必然性。
  1. 国家工业化是独立富强的当然要求和必要条件
  2. 对资本主义工商业改造是解决工人阶级与资产阶级矛盾的必然
  3. 个体农业手工业改造是发展生产力、实现工业化的客观需要
  4. 具备了实行改造的经济政治条件与社会基础
4. 《中华人民共和国宪法》的内容。
  1. 确立人民代表大会制度为我国根本政治制度

  3. 规定公民权利义务
  4. 是第一部社会主义类型宪法

  2. 结束四分五裂，实现国家基本统一
  3. 人民成为国家主人，进入发展进步新纪元
  4. 壮大世界和平民主社会主义力量
  5. 鼓舞被压迫民族和人民解放斗争
2. 试述中国共产党在过渡时期的总路线和总任务。
  1. 总路线：在一个相当长时期内，逐步实现国家社会主义工业化
  2. 并逐步实现国家对农业、手工业和资本主义工商业的社会主义改造（一化三改）
3. “文化大革命”的历史教训。
