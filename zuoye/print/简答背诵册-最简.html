近代史（40 道）

第1章　进入近代后中华民族的磨难与抗争

1. 简述鸦片战争成为中国近代史起点的原因。
  1. 中国主权和领土完整遭到破坏，开始沦为半殖民地半封建社会。
  2. 自然经济逐步解体，中国被卷入资本主义世界市场。
  3. 社会主要矛盾变为帝国主义与中华民族、封建主义与人民大众的矛盾，反帝反封建成为近代中国的双重任务。
2. 简述近代中国社会的两对主要矛盾。
  1. 帝国主义和中华民族的矛盾。
  2. 封建主义和人民大众的矛盾。
  3. 当资本—帝国主义发动侵略战争时，民族矛盾上升为主要矛盾。
3. 简述近代中国民族资产阶级的两面性。
  1. 受帝国主义压迫和封建主义束缚，有反帝反封建的革命要求。
  2. 同帝国主义、封建主义并未完全断绝经济联系，没有彻底的反帝反封建勇气。
  3. 这种两面性决定了它不能领导中国革命取得胜利。
4. 简述近代中国反侵略战争失败的根本原因。
  1. 根本原因是中国封建王朝的腐朽，统治集团妥协苟安。
  2. 经济技术落后也是重要原因，但不是决定性的。
  3. 正因如此，要争得民族独立，必须首先改变中国的社会制度。

第2章　不同社会力量对国家出路的早期探索

1. 简述洋务运动失败的原因。
  1. 洋务派具有封建性，对外国又有依赖性。
  2. 中央缺乏健全有力的领导核心，地方各自为政。
  3. 企图以封建制度为体、西方技术为用，无法使中国富强。
2. 简述资产阶级维新派自身弱点和局限的主要表现。
  1. 不敢否定封建主义。
  2. 对帝国主义抱有幻想。
  3. 惧怕人民群众。
3. 简述戊戌维新运动是一场思想启蒙运动的意义。
  1. 维新派大力传播西方资产阶级的社会政治学说和自然科学知识。
  2. 批判封建君权和封建纲常伦理，有利于民主思想传播，形成思想解放潮流。
  3. 主张采用西方近代教育制度、兴办新式学堂，推动了中国教育的近代化。
4. 简述太平天国农民战争的历史意义。
  1. 沉重打击了清王朝的封建统治。
  2. 冲击了孔子和儒家经典的正统权威。
  3. 有力打击了外国侵略势力，显示了农民阶级的反抗力量。

第3章　辛亥革命与君主专制制度的终结

1. 简述中华民国南京临时政府的性质。
  1. 人员构成上，资产阶级革命派控制着这个政权。
  2. 各项政策措施集中体现了中国民族资产阶级的愿望和利益。
  3. 临时参议院颁布《中华民国临时约法》，是中国历史上第一部具有资产阶级共和国宪法性质的法典。
2. 简述辛亥革命的历史意义。
  1. 推翻了清王朝，结束了在中国延续两千多年的封建君主专制制度。
  2. 建立了中国历史上第一个资产阶级共和政府，使民主共和观念开始深入人心。
  3. 推动了中国社会变革，促使中国的思想解放和社会风俗演进。
3. 简述辛亥革命时期资产阶级革命派的骨干力量。
  1. 骨干力量是一批资产阶级、小资产阶级知识分子。
  2. 他们宣传民主革命思想，组织革命团体。
  3. 并进而发动反清武装起义，成为革命派的中坚。
4. 简述辛亥革命失败的原因。
  1. 不能提出彻底的反帝反封建纲领。
  2. 不能充分发动和依靠人民群众，尤其是广大农民。
  3. 不能建立坚强的革命政党，作为团结一切革命力量的强有力的核心。

第4章　中国共产党成立和中国革命新局面

1. 简述新文化运动的历史意义。
  1. 以进化论和个性解放为武器批判孔学，动摇了封建正统思想的统治地位。
  2. 提倡民主、反对专制，提倡科学、反对迷信盲从，切中时弊。
  3. 冲决了禁锢人们思想的闸门，为各种新思想的涌流打开了通道。
2. 简述中国共产党早期组织的工作。
  1. 研究和宣传马克思主义。
  2. 到工人中去开展宣传和组织工作。
  3. 进行建党问题的讨论和实际组织工作。
3. 简述中国早期信仰马克思主义的三类代表人物。
  1. 五四运动以前的新文化运动的精神领袖。
  2. 五四运动中的左翼骨干。
  3. 一部分原中国同盟会会员、辛亥革命时期的活动家。
4. 简述五四运动的历史意义。
  1. 以彻底反帝反封建的姿态出现，比辛亥革命更彻底。
  2. 真正成为群众性的革命运动，工人阶级开始作为独立力量登上政治舞台。
  3. 促进了马克思主义在中国的传播及其与中国工人运动的结合。

第5章　中国革命的新道路

1. 简述遵义会议的历史意义。
  1. 开始确立以毛泽东为主要代表的马克思主义正确路线在党中央的领导地位。
  2. 在最危急关头挽救了党、挽救了红军、挽救了中国革命。
  3. 标志着中国共产党在政治上开始走向成熟。
2. 简述1927年建立的国民党政权在全国实行独裁统治的主要表现。
  1. 建立了庞大的军队和全国性特务系统。
  2. 大力推行保甲制度。
  3. 厉行文化专制主义。
3. 简述中华苏维埃共和国实行的各级工农兵代表大会制度。
  1. 由苏维埃共和国公民直接选举产生乡工农兵代表大会代表，选举乡苏维埃政府组成人员。
  2. 在此基础上逐级召开区、县、省和全国工农兵代表大会，选举各级政府。
  3. 各级苏维埃政府广泛吸收工农群众代表参加政权管理。
4. 简述农村包围城市、武装夺取政权道路的主要内容。
  1. 土地革命是基本内容。
  2. 武装斗争是主要形式。
  3. 农村根据地是战略阵地。

第6章　中华民族的抗日战争

1. 简述中国人民抗日战争胜利的历史意义。
  1. 彻底粉碎了日本军国主义殖民奴役中国的图谋，捍卫了国家主权和领土完整，洗刷了民族耻辱。
  2. 重新确立了中国在世界上的大国地位，为世界反法西斯战争作出重大贡献。
  3. 促进了中华民族的觉醒，开辟了中华民族伟大复兴的光明前景。
2. 简述延安整风运动的主要内容及其意义。
  1. 主要内容：反对主观主义以整顿学风、反对宗派主义以整顿党风、反对党八股以整顿文风。
  2. 方针是「惩前毖后、治病救人」，通过批评与自我批评达到团结。
  3. 意义：使全党确立了实事求是的思想路线，为抗战胜利和新民主主义革命胜利奠定思想基础。
3. 简述抗日战争时期新民主主义理论系统阐明的意义。
  1. 揭示了中国革命的发展规律，回答了革命的一系列基本问题。
  2. 为中国革命胜利提供了理论指导。
  3. 标志着毛泽东思想得到多方面展开而达到成熟。
4. 简述抗日民族统一战线的特点。
  1. 广泛的民族性和复杂的阶级矛盾。
  2. 国共双方有政权有军队的合作。
  3. 没有正式的固定的组织形式和协商一致的具体的共同纲领。

第7章　为创建新中国而奋斗

1. 简述抗日战争胜利后美国实施的扶蒋反共政策。
  1. 形势对国民党不利时，力促国共谈判，企图用和平手段诱骗中共向国民党投降。
  2. 从各方面大力加强国民党的力量。
  3. 一旦和谈目的不能实现，便帮助国民党与中共决战，使中国成为美国的附庸。
2. 简述新民主主义革命胜利的基本经验。
  1. 建立广泛的统一战线。
  2. 坚持革命的武装斗争。
  3. 加强共产党自身建设。
3. 简述中共七届二中全会的主要内容。
  1. 提出党的工作重心由乡村转移到城市。
  2. 规定了革命胜利后党在政治、经济、外交方面的基本政策。
  3. 提出「两个务必」，警惕资产阶级糖衣炮弹的攻击。
4. 简述新中国成立的历史意义。
  1. 结束了帝国主义、封建主义和官僚资本主义的统治，结束了极少数剥削者统治广大劳动人民的历史。
  2. 实现了民族独立和人民解放，人民当家作主。
  3. 是马克思主义在中国的胜利，改变了世界政治格局，鼓舞了被压迫民族的解放斗争。

第8章　社会主义基本制度在中国的确立

1. 简述新中国成立初期中国共产党面临的问题和考验。
  1. 能不能保卫住人民胜利的成果，巩固新生的人民政权。
  2. 能不能战胜严重的经济困难，迅速恢复和发展国民经济。
  3. 能不能巩固民族独立，维护国家主权和安全；能不能经受执政考验、继续保持谦虚谨慎不骄不躁和艰苦奋斗作风。
2. 简述1952年我国开展的「五反」运动的内容。
  1. 反对行贿。
  2. 反对偷税漏税。
  3. 反对盗窃国家财产。
  4. 反对偷工减料。
  5. 反对盗窃经济情报。
3. 简述抗美援朝战争胜利的意义。
  1. 粉碎了帝国主义扩大侵略的野心，维护了亚洲和世界和平。
  2. 保卫了新生的人民共和国，提高了新中国的国际威望。
  3. 使中国人民极大地增强了民族自信心和自豪感，赢得相对稳定的和平环境。
4. 简述社会主义基本制度在中国确立的意义。
  1. 为当代中国一切发展进步奠定了根本政治前提和制度基础。
  2. 使广大劳动人民真正成为国家的主人。
  3. 是马克思列宁主义关于社会主义革命理论在中国的正确运用和创造性发展的结果。

第9章　社会主义建设在探索中曲折发展

1. 简述1979年邓小平提出的坚持四项基本原则及其重要性。
  1. 坚持社会主义道路，坚持人民民主专政，坚持共产党的领导，坚持马克思列宁主义、毛泽东思想。
  2. 这是实现四个现代化的根本前提。
  3. 如果动摇了这四项基本原则中的任何一项，那就动摇了整个社会主义事业、整个现代化建设事业。
2. 简述邓小平提出的「一个国家、两种制度」的构想。
  1. 一个中国是前提和核心。
  2. 国家的主体坚持社会主义制度。
  3. 香港、澳门、台湾保持原有的资本主义制度长期不变。
3. 简述中共十一届三中全会的历史意义。
  1. 结束了徘徊局面，开始全面纠正「文化大革命」及其以前的「左」倾错误。
  2. 重新确立了马克思主义的思想路线、政治路线、组织路线。
  3. 作出把工作重点转移到社会主义现代化建设上来和实行改革开放的决策。
4. 简述邓小平南方谈话的主要内容。
  1. 计划和市场都是经济手段，社会主义也可以搞市场经济。
  2. 提出判断改革和各方面工作是非得失的「三个有利于」标准。
  3. 强调坚持党的基本路线一百年不动摇，发展才是硬道理。

  1. 中国共产党在革命性锻造中更加坚强有力。

4. 简述中国特色社会主义进入新时代的重大意义。
  1. 意味着近代以来久经磨难的中华民族迎来了从站起来、富起来到强起来的伟大飞跃。

习思想（74 道）

第1章　导论

1. 简述习思想科学体系中的“六个必须坚持”。
  1. 人民至上、自信自立、守正创新、问题导向、系统观念、胸怀天下。
  2. 是习思想世界观和方法论的集中体现。
2. 简述“两个确立”的决定性意义。
  1. 确立习近平同志党中央的核心、全党的核心地位；确立习思想的指导地位。
  2. 是新时代取得历史性成就与变革的决定性因素。
  3. 是应对一切不确定性的最大确定性、最大底气、最大保证。
3. 简述习近平新时代中国特色社会主义思想的历史地位。
  1. 当代中国马克思主义、二十一世纪马克思主义，中华文化和中国精神的时代精华，实现新的飞跃。
  2. 继承发展马列毛邓三科，开辟马克思主义中国化时代化新境界。
  3. 是民族复兴行动指南，是新时代党和国家事业发展的根本遵循。

第2章　新时代坚持和发展中国特色社会主义

1. 简述为什么新时代要坚持和发展中国特色社会主义。
  1. 中国特色社会主义是历史和人民的选择。
  2. 中国特色社会主义是社会主义而不是其他什么主义。
  3. 中国特色社会主义既坚持了科学社会主义基本原则，又根据时代条件赋予其鲜明的中国特色。
2. 简述中国特色社会主义进入新时代的内涵。
  1. 是承前启后、继往开来、在新的历史条件下继续夺取中国特色社会主义伟大胜利的时代。
  2. 是决胜全面建成小康社会、进而全面建设社会主义现代化强国的时代。
  3. 是全国各族人民团结奋斗、不断创造美好生活、逐步实现全体人民共同富裕的时代。
3. 简述中国特色社会主义进入新时代的意义。
  1. 意味着近代以来久经磨难的中华民族迎来了从站起来、富起来到强起来的伟大飞跃。
  2. 意味着科学社会主义在21世纪的中国焕发出强大生机活力。
  3. 意味着中国特色社会主义道路、理论、制度、文化不断发展。
4. 简述为什么要坚定道路自信、理论自信、制度自信、文化自信。
  1. 道路是必由之路；理论是正确理论；制度是根本保障；文化是精神力量。
  2. 四者统一于中国特色社会主义伟大实践。
  3. 说到底要坚定文化自信。
5. 简述统筹推进“五位一体”总体布局和协调推进“四个全面”战略布局。
  1. “五位一体”总体布局各方面相互联系、相互促进、不可分割。
  2. 要按照“五位一体”总体布局的整体性目标要求。
  3. “四个全面”新的时代内涵：全面建设社会主义现代化国家是战略目标。

第3章　以中国式现代化全面推进中华民族伟大复兴

1. 简述中国式现代化的中国特色。
  1. 人口规模巨大；全体人民共同富裕。
  2. 物质文明和精神文明相协调；人与自然和谐共生。
  3. 走和平发展道路。
2. 简述中国式现代化的重要原则。
  1. 坚持和加强党的全面领导。
  2. 坚持中国特色社会主义道路。
  3. 坚持以人民为中心的发展思想。
3. 简述实现中华民族伟大复兴的中国梦的本质。
  1. 国家富强。
  2. 民族振兴。
  3. 人民幸福。
4. 简述中国式现代化的本质要求。
  1. 坚持党的领导；坚持中国特色社会主义。
