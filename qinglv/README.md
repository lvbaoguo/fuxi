# 情侣 · 正式版后台（手机云端入口）

线上：https://lvbaoguo.github.io/fuxi/qinglv/

## 这是什么

GitHub Pages **只有静态页**，微信/OpenClaw 仍在你家电脑的 `127.0.0.1:18772`。

手机用法：

1. **电脑**开着管理者后台（18772）
2. **电脑**跑穿透：`tools/情侣体验/管理者后台/start_phone_tunnel.sh`
3. 手机打开上面的链接 → 把穿透给出的 `https://….loca.lt` 填进页顶并保存
4. 之后即可在手机盯正式/测试通道（人设、提醒、对话刷新等）

电脑不用时，手机页保存不了、也控不了 Bot（这是正常的）。

## 同步静态页

从本机后台拷贝最新 `index.html`：

```bash
./sync-from-admin.sh
# 再按 fuxi 规矩推：./../push-pages.sh
```
